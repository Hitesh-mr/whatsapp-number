# 📱 WhatsApp Message Scheduler with Python

This project uses **PyWhatKit** to schedule and send WhatsApp messages automatically at a given time.  
Perfect for reminders, birthday wishes, or just surprising your friends with perfectly timed messages! 🎉  

---

## ✨ Features
- ⏰ Schedule WhatsApp messages at a specific time  
- ✅ Automatically opens WhatsApp Web and sends the message  
- 🔒 Ensures the scheduled time is in the **future** (avoids mistakes)  
- 🐍 Simple and lightweight Python script  

---

## 🚀 How It Works
1. The script checks the current time.  
2. If your scheduled time is valid (in the future), it uses **PyWhatKit** to schedule the message.  
3. WhatsApp Web will open in your browser and send the message automatically.
